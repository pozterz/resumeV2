# Tharathep Numuean (Jo) — Resume

A single static page: `index.html`, with no build step and no JavaScript.

- Fonts come from Google Fonts (Bricolage Grotesque, Instrument Serif, Geist, Geist Mono).
- Responsive breakpoints at 1100px (tablet) and 640px (phone).

## Preview locally

```sh
npx serve .
```

## Deploy

GitHub Pages: Settings → Pages → *Deploy from a branch* → `master` / root.
`.nojekyll` makes Pages serve the files as-is.
